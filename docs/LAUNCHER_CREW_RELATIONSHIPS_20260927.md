# 草帽房間：說話方式、關係與表演重寫 — 2026-09-27

範圍：1.1.15 候選版 `desktop/launcher-room-dialogue.js` 與 `scripts/launcher_room_dialogue_qa.js`。使用者明確否定 1.1.14 的角色呈現後，本次重新閱讀官方人物介紹，再重寫房間台詞。這份文件不宣稱美術已獲得使用者接受，不是部署證明，也不把資料測試數量當成海迷評價。

## 先承認舊稿的具體問題

1. 舊稿經常以「提出小工作 → 專業說明 → 聽從 → 道謝／稱讚」結束。135 場字串不重複，並不表示 135 場的戲劇節奏不同。
2. 舊索隆常主動解釋體貼，舊魯夫常先詢問規則再乖乖服從；這會抹掉寡言與衝動的差異。應讓關心出現在他們做的選擇，少讓人物把自己的優點解說出來。
3. 「你也休息，等等我們再繼續」「有你幫忙……」等和氣句式太密集。羅賓、甚平與布魯克都變成溫和輔導員；拿掉名字後，語調容易互換。
4. 舊 `talk` 預設對應大笑圖，`explain`／`think` 對應使用家具圖；說平常話也可能咧嘴，站著講話卻像在操作不存在的工具。這是資料表演方向的問題，不能只怪圖片。

## 動作和表情的實際契約

保留原有 action token 與八個完整人物 pose。對話資料沒有把身體切開，也沒有新增虛構動畫能力。

- `talk`、`explain`、`think`、`reassure`、`tease`：`focused + idle`。普通說話、思考、羅賓的乾幽默不強制大笑或徒手操作工具。
- `laugh` 與新增的自然微笑 `smile`：`happy + talk_happy`；`admire`／`startled`：`surprised + surprised`；`protest`：`annoyed + talk_annoyed`。
- `listen`：`focused + listen`，使用已存在的完整聆聽圖。不是只在氣泡印「聆聽」。
- `offer`／`bow`：`focused + wave`，表示招呼／致意；現有圖只提供招呼，不能聲稱已做出遞杯或鞠躬動畫。
- 單獨家具 `activity()` 的 `work` 仍為 `focused_use`。自由站立的雙人對話把 `work`／`rest` 限為 `idle`，避免在沒有工具、沒有座位時做出懸空工具姿勢或坐姿。
- 索隆／喬巴的高處段落改成在書架旁指出想拿的書，不再描述喬巴已被舉上肩膀。現有素材沒有雙人抱起動畫，不能靠台詞假稱演到了。

需要由房間引擎與實際畫面確認：雙方先整體轉向再說話；同一回合只留說話者氣泡；聆聽者的反應應在適合的時間出現；不把笑、抗議、驚嚇都當成大幅搖擺；演完收回中性站姿。若想做出按鈕按下、遞茶、合奏、拿取道具的具體肢體動作，必須有對應完整人物與道具鏡位，不能由現有 token 或本文視為已完成。

## 家具可用性的嚴格範圍

`scene(first, second, index, context)` 在 `context.availableFurnitureKeys` 是陣列時，只可選 `tags` 為空或至少一個 tag 在該陣列內的場景。偏好家具選擇、近期場景迴避及冷卻回退都留在這個 eligible 集合中；無家具陣列只選無家具日常。沒有傳入陣列的舊 API 保留完整场景池。45 配對現在都至少有一場無家具對話。

房間 runtime `desktop/launcher-room.js` 傳入距離兩位角色任一位不超過 170 房間座標單位的已擺放家具，不再把整間房任何角落的家具當成眼前道具。這只限制話題成立的環境，不能替代真的按按鈕、抱物品、端湯或操舵動畫。

## 獨立審查條件

此項需要另一位審查者讀稿及房間播放，不能由作者的字串檢查代替。

1. **說話者可辨**：遮住姓名，在同一段四句中，兩人的用字、長短、重點是否有差別？不能只是把姓名換掉仍完全成立。
2. **關係會改變回答**：同一句騙人布誇口，魯夫／喬巴、娜美、甚平、羅賓是否接得不同？香吉士對索隆與兩位女士是否有實質差別？
3. **有來有回**：第二句接第一句的關鍵；第三句使情況前進或轉彎；第四句完成此小事，不硬加「我們都很可靠」的總結。
4. **特徵不等於口頭禪**：可認得人物，但沒有每場同一梗；喬巴能管醫療、騙人布能解技術、娜美能判斷航線，不能只靠可愛、膽小或貪財。
5. **沒有偷加關係**：不用官方未確認的戀情、親屬、秘密或重大新能力補戲；對混合服裝收藏場景保留時期界線。
6. **演得出來**：四句不是一張大笑圖輪流冒泡。逐句看完整人物姿態、另一人的反應、轉向、道具及家具是否真在現場；沒有相關圖的實體動作不能記作完成。
7. **節奏可讀**：在實際縮小房間看完四回合，字不遮住臉、不被下一句截斷；笑點留出反應，不把持續抗議表演成真正敵對。
