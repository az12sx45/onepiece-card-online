## 本次修正（不是新增自創技能）

1. 海軍 5／正義 5：只需放回實際抽到的張數。牌堆為零時不要求回牌；正義 5 剩一張時只抽一、回一。
2. 海賊 5：不足三張時保留原先頂牌，海軍檢視公開牌後洗入補足，再由施放者私下排序頂部三張。包含本次已打出的五號牌；其他玩家看不到頂牌。
3. 正義 1：多個對手被猜中時，按海軍之後的實際席位順序補抽；海軍不在第 0 席也正確。
4. 海賊 2：選隊友後，海軍可私下重排手牌，再讓指定隊友選牌查看。
5. 海軍被猜中一張或兩張同點數牌均使用私下確認；旁觀者只收到一般等待狀態，不能從選擇類型或是否出現確認推知兩張相同數字。只擊敗一張。
