# iOS 測試版工作紀錄

目標：iPhone 11 Pro Max，使用者回報 iOS 27.2；完整啟動器與 card／board／chess 三款遊戲。

來源：正式 launcher-flick-reward-r12 的 dddf2486ec277c27ace5b6573e662728116676d6。使用獨立受管理工作樹與 codex/tabletop-ios-trial 分支，沒有覆寫正式 Windows 程式與玩家資料。

## 本次實作

- iOS UIKit／WKWebView 容器，三款遊戲程式內附，素材按需下載至 App 私有快取；不是原生遊戲引擎重寫。只綁定 127.0.0.1 的穩定本機 HTTP 來源維持 localStorage／相對網址，原生串流支援 Range，下載上限 4 路。遊戲 Socket.IO 指向正式 HTTPS 伺服器。
- iOS Keychain 保存 session。沿用 AuthService／SocialService 的驗證、Socket.IO 協定與 46 項 renderer 介面，密碼不寫入持久 session。
- 安裝素材、取消、移除快取與下載進度使用原生檔案層；每個下載核對 bytes 和 SHA256。支援返回啟動器。
- 資源準備檢查簽署內容清單與固定遊戲 manifest，換行转换也必須符合原始 SHA256，不能跳過驗證。
- 建立 macOS GitHub Actions 編譯與 unsigned IPA 輸出流程，供 Windows 另行免費簽署。內容更新核對既有 Ed25519 簽章與每個 SHA256，完成下載後原子套用；iOS 核心二進位更新須重新簽署安裝，不能執行 Windows EXE。

## 尚未完成

- 內容更新已實作但尚待原生簽章 QA／最新雲端編譯與實機驗證。iOS 核心更新採重新安裝；既有桌面版執行檔下载／執行介面不會在 iOS 假稱成功。
- 手機版畫面、音訊／影片、custom scheme 下的三款遊戲網路與存檔相容性尚待 iPhone 驗證。
- 原生快取、下載取消／共享快取移除、WebKit 載入與實機記憶體尚待編譯及實機測試。下載功能目前尚不宣稱可離線完整遊玩。
- 沒有宣稱 PWA 卡死問題已解決。桌面來源與 native cache 不代表遊戲畫面已達效能標準。
- LATTICE tools 本階段未提供，未建立假 task_ref、未聲稱圖譜或持久證據寫入成功。
