# Launcher 1.2.7 小遊戲檢查

檢查方式：實際 Chromium 載入候選版 launcher.html、CSP、CSS 與程式。操作使用真實經過時間，串接現有 server 函式與隔離 PGlite。不是玩家真人盲測、正式帳號購買或實體手機測試。

## 是否比等待工作有趣

- 海上補給有具體選擇：同一批可有一箱或兩箱符合訂單，必須全部選對。後半輪時間縮短，漏選或多選會中斷連擊。
- 甲板特訓讓完整角色在甲板上移步。三到五步安全路線需要記憶；同方向連續出現仍有明確亮暗節拍，不會誤看成一個長提示。
- 工作與訓練採不同操作；一次約半分鐘，不靠長時間掛網。失敗同場最多重試兩次，不追加已用掉的次數或精神。
- 訓練可先自由練習，冷卻期間也能玩，沒有獎勵與精神消耗。介紹先說明代價，按開始才消耗。
- 這是短時間基地日常挑戰，尚未宣稱有大型動作遊戲或長期關卡的深度。真人是否覺得好玩仍需實際玩家回饋。

## 航海王角色與畫面

- 沿用已審核的完整人物方向圖，不拆頭、不鏡射身體、不用 CSS 自畫角色。canvas 保留 384 像素來源。
- 使用 GPT 畫出的甲板與三種物資箱。介面寫「食材箱／工具箱／書籍航圖箱」，避免箱子圖與單一小物名称不符。
- 艾斯是白鬍子海賊團第二隊隊長，不寫成草帽團船員或獨立船長。台詞沒有捏造他與其他角色的戀愛關係。
- 不把所有人寫成霸氣使用者。羅賓以觀察與整理、娜美以清單和方向、香吉士以食材和穩步、喬巴以安全與關心回應。
- 11 位已開放角色各有 3 句成功及 3 句失誤反應，循序輪替，不連續重複同一句；未開放角色没有小遊戲入口。
- 已檢視桌機補給與甲板特訓、390px 艾斯特訓截圖。甲板可見、文字可讀，人物沒有拆分，按鍵足夠大。
- 追加實際個人頁的羅賓整合：從人物圓輪進入工作／訓練，使用 `robin_v2` 新肖像與完整方向圖。桌機與 390px 實圖已檢視，頭身連接完整，三箱名稱不溢出。新資產無 404，canvas 保留 384 像素；角色圖本身的完整美術品質驗收仍另有羅賓專項報告。

## 由檢查實際修正

1. 把物資移動與點擊區分開，點擊區保持穩定，避免滑鼠難以點中。
2. 換輪後保留對話框焦點，鍵盤 1/2/3、方向鍵不會失效。
3. 遺失 ACK 後重送會讀回已完成的輪次，不重算或重領。
4. 錢包不足空間時保留成果，不自動反覆結算；購物後回到工作入口領取同一場成果。
5. 取消確認不重置本輪時間或重播路線，避免利用開關確認框無限重看。
6. 切換帳號後晚到的開始回覆不會重開原帳號挑戰。伺服器保存原場次至取消／失效，沒有自動發獎。
7. 真圓輪整合抓到 Esc 冒泡至舊房間 handler 會移走 modal 焦點；補上停止冒泡後，純鍵盤訓練的關閉確認仍保有正確焦點。
