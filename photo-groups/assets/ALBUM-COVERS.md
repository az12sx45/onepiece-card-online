# 電子祝福書封面與封底

`album-cover-front.png` 與 `album-cover-back.png` 是 2026-11-22 依使用者要求，以內建 imagegen 分別製作的原創底圖。兩張均為 1086×1448（3:4）PNG，奶油白紙紋、玫瑰粉花卉與香檳金細邊；保留原始比例使用，沒有放大裁切或硬拉伸。

圖片本身沒有新人、姓名、祝福、QR 或假文字。電子書程式另外疊上既有 `couple-5.jpg` 真實合照及可讀文字；沒有 AI 重畫新人臉孔。前封安全區為中央標題、合照與下方收錄資訊，後封中央保留感謝文字。兩張圖只供電子書使用，不改電視或賓客查詢頁。

控制台匯出時將這兩張 PNG 與其他圖片內嵌進 PDF／離線 HTML。下載後閱讀不需要圖片服務、婚禮 API 或管理金鑰。
