電腦下載 Windows 桌遊啟動器；Android 手機下載 PIRATE ODYSSEY，橫向遊玩航海錄。

請依要安裝的裝置選擇版本。下載會在你點選按鈕後開始。

↓下載 Windows 桌面版

  1. 下載並安裝啟動器。

  3. 選擇遊戲，完成內容下載後開始遊玩。

適合目前的 Android 裝置

PIRATE ODYSSEY

Android 8.0 以上 · 手機橫向版

↓下載 Android APK

v026 · 測試版 · 安裝檔約 355 MB

  1. 下載 APK，開啟下載完成的檔案。

  3. 開啟 PIRATE ODYSSEY；後續可在 App 內檢查更新，有適用差量時只下載差量。

已經安裝過？

Windows 請從既有啟動器更新；Android 請從 App 內檢查更新，下載後依系統提示安裝。兩個平台使用各自的更新通道。

選擇適合的版本

Windows 版本適用 64 位元電腦；Android APK 適用 Android 8.0 以上。手機版目前以航海錄測試為主。iPhone、iPad 與 macOS 暫無安裝版本。
