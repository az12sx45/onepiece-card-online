電腦・手機下載

你的航程，繼續前進

下一段冒險，
在你的裝置啟航。

電腦可下載 Windows 桌遊啟動器。Android 手機、iPhone 與 iPad 可下載 PIRATE ODYSSEY。

請依要安裝的裝置選擇版本。下載會在你點選按鈕後開始。

適合目前的 Windows 裝置

桌遊啟動器

Windows 64 位元

↓下載 Windows 桌面版

v1.2.34 · 安裝檔約 325 MB

  1. 下載並安裝啟動器。
  2. 使用原本帳號登入啟動器。
  3. 選擇遊戲，完成內容下載後開始遊玩。

適合目前的 Android 裝置

PIRATE ODYSSEY

Android · 手機橫向版

↓下載 Android APK

v067 · 安裝檔約 480 MB

  1. 下載 APK，開啟下載完成的檔案。
  2. 若系統詢問，允許此瀏覽器安裝應用程式，再完成安裝。
  3. 開啟 PIRATE ODYSSEY；後續可在 App 內檢查更新，有適用差量時只下載差量。

適合目前的 iPhone 或 iPad

PIRATE ODYSSEY

iPhone／iPad · iOS／iPadOS 16 以上

↓下載 iOS IPA

v066 · 需自行簽署 · 安裝檔約 436 MB

  1. 在電腦下載 IPA，使用 USB 接上 iPhone 或 iPad。
  2. 使用 iLoader 簽署並安裝 IPA。
  3. 到「設定 → 隱私權與安全性 → 開發者模式」啟用，重新啟動後確認。
